## 🧠 Python Quiz Game Application

## 📌 Project Overview
The Python Quiz Game Application is a simple command-line quiz program that asks users multiple-choice questions, accepts their answers, calculates the final score, and displays the result at the end of the quiz.

## ✨ Features
- Display multiple-choice quiz questions
- Accept user input
- Check correct and incorrect answers
- Calculate the final score
- Display the quiz result
- Uses Python loops and conditional statements

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## 📂 Project Structure
```
Quiz Game/
│── quiz_game.py
│── README.md
```

## ▶️ How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python quiz_game.py
```

4. Answer the quiz questions by entering **A, B, C, or D**.
5. View your final score and result.
